# Demo deployment

This CLI is a demonstration. Its deploy command prints a result; it does not
deploy a real service.

1. Run `argrail-demo help deploy` to inspect the supported options.
2. Start with `argrail-demo deploy --environment dev --replicas 1 --dry-run`.
3. Explain the result before proposing a production example.

See [the examples](references/examples.md) for copyable commands.
